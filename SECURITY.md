# Security Policy

## Supported versions

We patch the latest minor of the latest major. Older minors do not receive
security updates — please upgrade.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | ✅        |
| < 0.2   | ❌        |

The matrix expands once we ship 1.0.0; at that point the latest two minor
lines will receive security patches.

## Reporting a vulnerability

**Please do not file a public GitHub issue for security bugs.** Public
issues are indexed and can be exploited before a fix lands.

Use one of these private channels:

1. **GitHub Security Advisories** (preferred) — open a draft advisory at
   <https://github.com/encorp-io/llm-open-proxy/security/advisories/new>.
   This gives us a private workspace, a tracking ID, and lets us
   coordinate a CVE if one is warranted.

2. **Email** — `security@encorp.io`. Encrypt with our PGP key if the
   issue is sensitive (key available on request).

Please include:

- A description of the issue and its impact (e.g. credential leak,
  cross-tenant data exposure, request smuggling)
- Steps to reproduce, ideally with a minimal failing test
- Affected versions and any known workarounds
- Whether you intend to disclose publicly, and on what timeline

## Response targets

- **Acknowledge receipt** within 2 business days
- **Initial assessment** (confirmed / not a vulnerability / needs more
  info) within 5 business days
- **Patch landed in main** within 14 days for high-severity issues; we
  may negotiate a longer window for issues that require coordinated
  multi-package fixes

We will credit reporters in the release notes unless they prefer to
remain anonymous.

## Scope

This package is a **pure translation library**. It does not run network
services, does not store credentials, does not log requests. The
security surface is intentionally small:

- **Bugs that mistranslate authenticated requests** (e.g. dropping an
  `Authorization` header, swapping API keys between tenants in a
  multi-tenant gateway built on top of this library) — in scope.
- **Bugs that mishandle untrusted JSON in upstream responses** (e.g.
  prototype pollution via a crafted tool_call payload) — in scope.
- **Bugs that bypass safety controls in upstream provider APIs** — out
  of scope; report those directly to the provider.
- **Bugs in user-facing applications that happen to use this library** —
  out of scope unless the root cause is a translation bug here.

## Provenance

Every published release includes a [Sigstore provenance attestation](https://docs.npmjs.com/generating-provenance-statements)
generated by GitHub Actions OIDC. You can verify the tarball came from
this repository's `release.yml` workflow run:

```bash
npm view @encorp.ai/llm-open-proxy --json | jq '.dist.attestations'
```

If `attestations` is missing or points at an unfamiliar repo/workflow,
**do not install** — open a security advisory immediately.
